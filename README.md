# Interactive Solar System Animation

A web-based interactive solar system animation that shows the planets orbiting around the sun with realistic proportions and detailed information.

![Solar System Animation](https://i.imgur.com/placeholder.jpg)

## 🌟 Features

- **Realistic Animation:** Planets orbit the sun at speeds proportional to their actual orbital periods
- **Interactive Controls:**
  - Zoom in/out using the mouse wheel
  - Pan by clicking and dragging
  - Click planets for detailed information
- **Visual Elements:**
  - Starry background with twinkling stars
  - Accurate planet colors and relative sizes
  - Planet labels and orbit paths (toggleable)
  - Saturn's distinctive rings
- **Educational Information:**
  - Detailed facts about each planet
  - Distance from the sun
  - Orbital period
  - Diameter
  - Unique characteristics

## 🚀 Quick Start

1. Clone this repository:
   ```
   git clone https://github.com/yourusername/solar-system-animation.git
   ```
   
2. Navigate to the project directory:
   ```
   cd solar-system-animation
   ```

3. Open one of these files in your web browser:
   - `index.html` - The solar system animation
   - `demo.html` - Introduction page with features and instructions

No server or build process required - it's pure HTML, CSS, and JavaScript!

## 🎮 Controls

- **View Planet Info:** Click on any planet or the sun
- **Zoom:** Use the mouse wheel to zoom in and out
- **Pan:** Click and drag (not on planets) to move around the solar system
- **Toggle Orbits:** Use the "Toggle Orbits" button
- **Toggle Labels:** Use the "Toggle Labels" button
- **Reset View:** Use the "Reset View" button to return to the default view

## 💻 Technologies Used

- **HTML5** - For structure and content
- **CSS3** - For styling and animations
- **JavaScript** - For interactivity and dynamic behavior
